# Dynamic Resume Generator 

A full-stack Flask application that generates tailored PDF resumes instantly.
Integrated with job search APIs to match skills with open positions.

##  Key Features
- **Dynamic PDF Generation:** Converts HTML forms to professional PDFs using `WeasyPrint`.
- **Job Market Integration:** Fetches live job data to suggest relevant skills.
- **Templates:** Multiple professional resume designs.

##  Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, Bootstrap
- **Database:** SQLite

##  How to Run
1. Clone the repo: `git clone https://github.com/rohith-talari/dynamic-resume-generator.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python app.py`
